# Bundled fonts

These 17 unmodified font files form the bridge's curated default font set.
`manifest.json` records the source and SHA-256 of every file. Sixteen come from
Typst assets 0.15.1 at its Cargo-recorded commit; `NewCM10-Book.otf` comes from
NewComputerModern 8.1.1 and replaces `NewCM10-Regular.otf`. The Book face has
independent GUST licensing and different glyph coverage. See
`Documentation/FONT-INVESTIGATION.md` and `Notices/` for terms, evidence and
compatibility limitations. Do not modify these files in place.
